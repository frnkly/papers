# ML & AI Safety papers in code

This repository collects machine learning and AI safety papers that I find interesting, along with code, notes, and experiments aimed at reproducing key results.

For each paper, I might include:

- Why I found it interesting
- Implementation details
- Reproduction attempts, successes, and failures
- Experimental results
- Observations and lessons learned
- Follow-up ideas and extensions

The goal is not to produce perfect reproductions, but to better understand the research through hands-on experimentation and to document what I learn along the way.
